# Leung, Ludwig, Sage & Sage, unpublished manuscript.

## Contents

`co2_study_analysis.Rmd` — main analysis (figures, tables, statistics).
`co2_timeseries.Rmd` — time-series acclimation experiment.
`make_tree.R` — species phylogeny (V.PhyloMaker2).
`C2 BS conductance v3.ipynb` — Bayesian MCMC fit of the von Caemmerer C2 model (Google Colab; `lmfit` + `emcee`). Produces `fit_results_*_FINAL.csv`, which the Rmd consumes.
